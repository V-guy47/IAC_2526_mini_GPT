# IAC_2526_mini_GPT
A mini ChatGPT, with fewer matrixes and introd. to AI thinking.
This repository contains the implementation of an AI model developed for my Introduction to Computer Architecture (IAC) course. In this group project, we built a simplified Transformer Architecture that uses an attention mechanism to predict the next token, in a given sequence.

This project had 3 specific deliveries:
- P1: Implementation of core mathematical functions
- P2: Integration of P1 for the full attention pipeline
- P3: Designed a custom sequential circuit functioning as a simple TPU 

TOOLS:
- RISC-V Assembly (RV32IM)
- Ripes Simulator (for running RISC-V code sequentially)
- Logisim (for the design of the TPU)
